Hooks

Import / export

Saves .data (logs, state, stats) and .memory (labeled learning examples) as one zip file in a folder. With a password the file is encrypted (.hbk). Import takes a backup file, or a folder (newest backup in it) and overwrites files with the same name.


  

  

    
Global skills

      
Skills both tools load. Delete removes the skill from Claude and Codex (the folder goes to Trash, so it can be restored). Sync adds the missing link where a skill exists in only one tool.

      

      

    

    
Project-only skills

      
Found in project folders and not global. Tick one to include it in the export; Make global copies it to the global store and links both tools.

      

    

    
Plugins

      
Claude Code and Codex keep separate plugin lists. Add copies a plugin to the other tool; Delete removes it from both.

      

      

    

    
Plugins switched on in projects

      

    

    
Export / import

      
One zip with every global skill, the ticked project skills and the plugin list (an encrypted .hbk with a password). Import restores skills (old copies go to Trash) and merges plugins.
